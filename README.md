# Извлечение атрибутов товаров из поисковых запросов

Портфолио-проект по извлечению структурированных фактов из коротких запросов маркетплейса.

Финальная архитектура:

```text
запрос
  -> fastText: категория товара
  -> динамический shortlist из 5 атрибутов
  -> базовый GLiNER2
  -> пары «атрибут — значение»
```

## Основные результаты

Оценка проводилась на proxy-golden датасете из 1 000 примеров: синтетическая разметка с частичной ручной проверкой.

| Вариант | Span F1 | Attribute F1 |
|---|---:|---:|
| Полная схема категории | 0,6335 | 0,6653 |
| **Dynamic shortlist-5** | **0,7035** | **0,7674** |
| Shortlist-10 | 0,6358 | 0,6732 |

На Tesla T4 финальный пайплайн показал:

- p50: **27,0 мс**;
- p95: **40,4 мс**;
- fastText отдельно: около **0,02 мс**.

LoRA-дообучение на 221 438 автоматически размеченных примерах ухудшило Span F1 до 0,6596. Поэтому финальная система использует базовый GLiNER2. Этот эксперимент оставлен в репозитории как пример выбора модели по метрикам и анализа шума weak supervision.
